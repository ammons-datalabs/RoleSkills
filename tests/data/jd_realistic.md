# Integration Developer

## About the job

ACME Digital Solutions are experts in digital business enablement. We help organisations build the technology capabilities and solutions, through data & AI, integration and process automation, to solve business problems and help our clients be great at what they do.

Due to business growth, we have a permanent opportunity for an intermediate level Integration Developer, offering a clear pathway to grow your skills toward a Senior Developer role.

As part of the ACME Integration delivery services team, the role of Integration Developer is to develop integration solutions as specified to support the implementation of multiple types of Digital, ERP, SaaS and custom integration solutions. The Integration Developer will work as part of the broader project team and will be guided by the Integration Architect and Senior Integration Developer for solution delivery.

## This role will

- Undertake modern integration solutions development, testing and deployment tasks using Microsoft Azure services
- Support and participate in the technical design process for integration solutions
- Work collaboratively within a team on diverse large-scale enterprise integration solution projects
- Work within agile delivery approach with solution architects, developers, and testers

## To be successful in this role you will be able to demonstrate

- Qualification such as Bachelor and/or Master of Information Technology, Computing, Computer Science, Information Systems or similar
- The successful candidate is expected to have or acquire and maintain suitable Microsoft Azure certifications
- Some level of hands-on experience on some of below technologies:
  - API and web services (development and consumptions)
  - JSON and XML data formats
  - Microsoft Azure Integration Services - including Azure Functions, Logic Apps, Service Bus, Event Hub and Azure API Management etc.
  - Programming languages such as Python, JavaScript and Node JS
  - Unit testing tools such as PyUnit or JUnit
  - Source version control tooling such as Git/BitBucket
  - Web service/REST API testing tools such as SoapUI and Postman
- Experience in preparing technical design documentation and diagrams
- Knowledge of Object-oriented programing concepts
- Experience working with relational databases, data modelling and writing SQL queries
- Knowledge of, or be willing to learn DevOps capability around building CI/CD pipelines
- Good software engineering best practices (such as coding standards, code reviews and test-driven development)
- Good level of English written and verbal comprehension and communication skills
- Demonstrated experience in IT teams working in agile environments
- Strong problem solving, analysis and critical thinking skills

## Requirements

- Must have the right to work in Australia
- National police check required as part of the application process
