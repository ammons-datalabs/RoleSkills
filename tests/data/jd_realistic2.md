# Senior Software Developer

## About the Company

A fast-growing Australian tech company building modern, cloud-native solutions that simplify complex processes for professionals across industries. Our teams value clean architecture, automation, and collaboration — and we're scaling quickly.

If you're a senior engineer who enjoys working across cutting-edge Microsoft and Azure technologies, thrives in a collaborative environment, and wants to build meaningful products with modern cloud patterns, we'd love to hear from you.

## About the Role

As a Senior Software Developer, you'll design and develop scalable, secure software using C#.NET, Azure, and serverless technologies. You'll help shape architecture, mentor others, and deliver robust backend and web solutions within an agile team.

This role is ideal for someone who enjoys technical ownership, hands-on coding, and modern cloud development.

## What You'll Do

- Design and maintain backend systems in C#.NET
- Build and optimise serverless and event-driven applications using Azure Functions
- Use Terraform to manage Azure infrastructure as code
- Design and work with NoSQL databases (Cosmos DB, MongoDB)
- Contribute to front-end features built with React
- Apply SOLID principles, clean-code practices, and robust testing
- Collaborate across teams and mentor other developers

## Tech Stack

- Languages: C# / .NET (Core / .NET 6/7)
- Cloud: Azure (Functions, App Services, Event Grid, Service Bus)
- Infrastructure: Terraform (IaC)
- Front-End: React
- Database: NoSQL (Cosmos DB, MongoDB)
- Architecture: Event-driven, serverless, microservices

## About You

You're a proactive problem-solver who enjoys owning features end-to-end. You love clean, maintainable code and have experience delivering scalable cloud solutions.

## You'll bring

- Senior experience with C#.NET development
- Solid experience deploying and managing apps on Azure
- Hands-on experience with serverless or event-driven systems
- Proficiency in Terraform or other Infrastructure-as-Code tools
- Strong knowledge of NoSQL databases and data modelling
- Familiarity with React (nice to have)
- Strong understanding of SOLID principles and software design patterns
- Excellent collaboration and communication skills

## Bonus points for

- Experience with Event Sourcing or CQRS
- Knowledge of Kubernetes or container orchestration
- Background in SaaS or product-based environments

## Why You'll Love Working Here

- Work with a modern Microsoft/Azure stack and cutting-edge cloud tech
- Influence architecture and product direction
- Flexible working arrangements (remote)
- Supportive, collaborative culture
